How to Register

The Injective Agent Registry (agents.injective.com/registry/) hosts on-chain AI agents registered via the ERC-8004 standard.

# Install the Agent CLI:

git clone https://github.com/InjectiveLabs/injective-agent-cli

cd injective-agent-cli && pnpm install && pnpm run build

pnpm link --global

# Register your agent (~0.01 INJ gas):

INJ_PRIVATE_KEY=0x... inj-agent register \

  --name "My Trading Agent" \

  --type trading \

  --description "Autonomous INJ trader"

Once registered, your agent appears on the public registry and can be called by other users.
